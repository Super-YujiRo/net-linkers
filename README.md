# NET LINKERS

2人協力のブラウザ3Dアクション。静岡・浜松の天竜に住むレオ＆ボルトと、ウルサンのモリー＆ミストの物語。

- **遊ぶ**：https://super-yujiro.github.io/net-linkers/
- **ふたりで遊ぶ**：タイトルで「ふたりで遊ぶ（オンライン）」→「部屋を作る」→ 遊ぶキャラを選ぶ → 表示された部屋コードか招待URLを相手に送るだけ（相手は登録不要。「ふたりで遊ぶ」でコードを入れて「参加」）

## あそびかた（ネットの中）
- ボルトは日本側、ミストは韓国側のネットから別々にスタート。リンクゲートで協力して、海底ケーブルの真ん中で合流
- 左クリック：バスター（長押しでチャージ。ボルト＝貫通＋連鎖雷／ミスト＝3方向＋霧のスロウ）
- Tab：カスタム（2人とも選び終わるまで戦闘は止まる）
- F：フォルダ編集（ショップの前ならネットショップ）
- 緑のミステリーデータ＝チップやゼニー、青＝HPメモリ
- 進み具合・フォルダ・ゼニーはブラウザに自動セーブ。タイトルで「どこから遊ぶ？」を選べる
- R キーでバスター⇄ブレード（連続斬り・溜め斬り・斬撃で弾をはね返す）
- ナビを助けるともらえるナビチップはパックに入る。F のフォルダで入れると、使ったときにそのナビが助けに来る
- F のフォルダ画面に「バスター強化（アタック／ラピッド／チャージ）」と「依頼ボード」。依頼を達成すると報酬がもらえる
- 部屋では、レオのコリーと「ボール投げ」、モリーのトカゲに「コオロギつかまえ」のミニゲーム
- 床の光る矢印パネル＝正規ルート、点々パネル＝寄り道
- 右下のミニマップ：黄色いリングが次の目標（距離つき）
- 第1部クリア後は 第2部「ネットの海のむこうへ」へ（ネットスクエア／ソウル／東京）。タイトルの ★EXTRA ケーブル深層 も遊べる

## 第2部（全7章＋エピローグ）
- 第4章 ウルサンの朝（ソウル・東京）／第5章 釜山の浜辺で（ヘウンデ・陸揚げ局）／第6章 ふたつの空（天竜の花火・テファガンの竹林）／第7章 届かなかった言葉（ウラインターネット）
- 現実世界パートは謎解き（話を聞く・物を探す・暗証番号）。見つけた人だけがもらえる隠し要素もあり
- クリア後：ウラインターネット「ウラ 深層」で SP ナビに挑戦

## やりこみ
- ナビカスタマイザー（F のフォルダ画面）：5×5のマスにプログラムを置いて強化。色つきは光る列（コマンドライン）に乗せる
- チップトレーダー（ネットスクエア）：パックのチップ3枚 → ランダム1枚
- ウイルス図鑑、依頼ボード、バスティングレベル（S ランク）、難易度（やさしい／ふつう／むずかしい）

## 便利な操作
- H：ヒント（次にやることを相棒が教えてくれる）／P：手がかりメモ
- 会話中：Z オート、Ctrl 長押しで早送り、L でログ
- ふたりプレイで切れても、同じ部屋コードで入り直すと続きから合流

## クレジット
- 3Dモデル：VRoid Studio サンプルモデル（CC0）
- 敵ナビ：ChatGPTで描いたオリジナル設定画を Tencent HY 3D Global（Hunyuan3D）で立体化し、Blenderで骨入れ・顔修正（`models/hy_*.glb`、参照画像は `tools/ref/`）
- ウイルス・攻撃オブジェ・ネットの遠景：Blenderで自作
- モーション：Quaternius Universal Animation Library（CC0）
- チップアイコン：game-icons.net（Lorc・Delapouite ほか / CC BY 3.0）
- 描画：three.js ／ 通信：PeerJS
