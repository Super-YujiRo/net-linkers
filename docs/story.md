# LINK DIVERS 本編ストーリー設計（2026-10-17 合意）

方針：構成はエグゼ1（毎章くらしの機械が乗っ取られる→ネットで解決→黒幕が少しずつ見える→終盤で誕生のひみつ→本拠地決戦）。中身はオリジナル。
禁止：モリーの家族は出さない／お父さん呼び／韓国はクリア後のおまけ／「届かなかった言葉」テーマは使わない。

## 黒幕
- ロストリンク：ナビとオペレーターのつながりを断つ「切断コード」を作った組織。切られたナビは主人を失って暴走し、最後は〈ゼロ〉の命令だけを聞く。
- 〈ゼロ〉：オペレーターなしで生まれた最初のナビ。人とつながったナビを理解できず、全部切ろうとする。
- 九条レイジ：九条ネットワークス社長・〈ゼロ〉の生みの親。「人間はナビをこき使い、戦争や犯罪の道具にもする。ナビを人から解放して〈ゼロ〉ひとつで世界を正しく動かす」。昔、自分のナビ・クロウを古いサーバーに置き去りにした。
- 第5章のどんでん返し：〈ゼロ〉が九条とのつながりも切って裏切る。最後の敵は人の手を離れた〈ゼロ〉。
- ナビ誕生のひみつ：ナビの心はオペレーターとの毎日から育つ。ボルト（工場で、お父さんの機械とレオの毎日を見て育った）とミストは、切断コードを浴びても2人とのつながりで踏みとどまれる。

## 実験の拡大（なぜ暮らしをねらうか）
1. 干上がった天竜川（済）：ナビ1体（ダム）。「知らないコードで止めろと命令された」＝切断コードの初実験
2. 舞阪漁港の夜：港じゅうの仕事ナビ。家族のタチウオ釣りの夜、製氷機と船のGPSが止まる。ボス：ウェーブ。幹部シェイド初登場
3. 止まった遠州鉄道：鉄道の全ナビ。ボス：ライナー。クロウ初遭遇
4. モリーの会社：ビルの全社員のナビ（ミストも危ない）。モリー主役。ボス：ネオン。九条ネットワークスとの関係が見える
5. 天竜の花火大会：観客何千人ぶんの個人ナビ。ボス：ハナビ。ろーじーが九条の正体をつかむ。〈ゼロ〉が九条を切る
6. アクトタワー決戦：日本中→日韓海底ケーブルで世界へ切断コード。〈ゼロ〉、クロウの決着
